# TA39 WISE Testbed partner record

This repository publishes TA39's living partner-review record for the WISE Testbed and EdTech Impact integration.

## Publication model

- The substantive source is `TA39-WISE_EdTechImpact-API-Integration-Status-v20260909.md`.
- GitHub Pages renders that Markdown at `https://ta-39.github.io/wise-testbed/`.
- The Pages layout asks compliant crawlers not to index, follow, or archive the site.
- The site is public by link. It is not confidential or access-controlled.

## Maintenance rules

- Preserve the distinction between TA39's observations, counterpart confirmation, and joint agreement.
- Do not infer agreement from silence.
- Do not commit credentials, event payloads, participant identifiers, names, email addresses, student work, feedback text, revision-plan text, or uncontrolled classroom descriptions.
- Use Git history as the revision record while this remains the first published version. Add partner-facing decision and change logs only after the first substantive partner decision or document revision.
- Do not link this site from the public TA39 website or add it to a sitemap.

## Publishing

GitHub Pages publishes from the repository root on `main`. Changes move through the paired `staging` and `main` pull requests before production publication.
